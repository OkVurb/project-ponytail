# Project Ponytail

Some parts will be stripped & some initialization code was removed for you to reimplement :).
This codebase was heavily unmaintained and rushed for release.

Comments were stripped thru darklua & indentation was intentionally messed up.

Local initialization and build tooling are reconstructed. The timing editor includes a draggable timeline and read-only animation watcher. Public mantra and mesh maps are wired up; the private base timing database remains unavailable. See [INSTALL.md](INSTALL.md) for setup, [DATA_PROVENANCE.md](DATA_PROVENANCE.md) for data sources, and [VERIFICATION.md](VERIFICATION.md) for tested behavior and remaining live checks. A passing build is not a verified executor boot.
